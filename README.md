## Folha de Pagamento em C

Este projeto consiste em um programa desenvolvido na linguagem C que realiza o cálculo de uma folha de pagamento com base no valor da hora trabalhada e na quantidade de horas trabalhadas no mês.

## 📌 Funcionalidades
O programa calcula:
- Salário Bruto
- Desconto do INSS (10%)
- Desconto do Imposto de Renda (conforme faixa salarial)
- FGTS (11% do salário bruto — não é descontado)
- Salário Líquido

## 📊 Tabela de Imposto de Renda
- Salário Bruto até R$ 900,00 → Isento  
- Salário Bruto até R$ 1.500,00 → 5%  
- Salário Bruto até R$ 2.500,00 → 10%  
- Salário Bruto acima de R$ 2.500,00 → 20%  

## 🧮 Como funciona
1. O usuário informa:
   - Valor da hora trabalhada
   - Quantidade de horas trabalhadas no mês
2. O programa realiza os cálculos automaticamente
3. Os resultados são exibidos na tela

## 🛠️ Tecnologias utilizadas
- Linguagem C

## 📚 Objetivo
Projeto desenvolvido para fins acadêmicos, com o objetivo de praticar lógica de programação, cálculos condicionais e entrada/saída de dados em C.
